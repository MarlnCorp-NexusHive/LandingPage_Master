Arabic Hero Images Generator

Instructions:

  1. Click the "Generate Images" button to create placeholder Arabic hero images
  2. Right-click on each image and select "Save image as..."
  3. Save the light mode image as "marln-hero-image-arabic.png"
  4. Save the dark mode image as "marln-hero-image-arabic-dark.png"
  5. Place both images in your "images" folder
  6. Replace these placeholder images with your actual Arabic hero images
